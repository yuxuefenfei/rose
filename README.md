# 一束玫瑰 · Bouquet study

可从任意角度旋转、缩放的 Three.js 手绑花束：6 朵深红玫瑰、5 朵象牙白玫瑰、21 枝满天星（336 朵小花）、锯齿绿叶和酒红缎带。花头以不同高度和倾角组成圆润花冠，花茎在缎带处收拢，底部保留参差的剪切面。它是程序化艺术模型，不对应特定栽培品种。

## 运行

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

浏览器打开终端显示的地址，默认 http://127.0.0.1:5173 。

```sh
npm test
npm run build
npm run preview
```

## 交互

- 鼠标拖动 / 单指滑动：任意方向旋转，包括顶部与底部。
- 滚轮 / 双指捏合 / 工具栏加减：缩放。
- 快捷视角：全束、花冠细节、俯视。
- 自动旋转开关；拖动时自动暂停。手机触摸输入按帧合并，桌面鼠标保留惯性。
- 选中画布后：方向键旋转，加减键缩放，Home 复位。
- 遵循系统减少动态效果偏好，关闭默认旋转和相机过渡。

## 花束与材质

构图参考[红白玫瑰与满天星手绑花束](https://alaira-florist.com/product/wedding-bouquet-red-white-roses/)。所有花朵、分枝、叶片和缎带均为三维几何体。

玫瑰使用 40 片独立卷曲曲面，沿螺旋排列并加入不对称形变。基础折叠坐标参考 [Paul Nylander 的 Rose-Shaped Parametric Surface](https://nylander.wordpress.com/2006/06/21/rose-shaped-parametric-surface/)，在本项目中调整了高度、外缘、花瓣分片和摆放。

- 花瓣颜色纹理由内置 imagegen 生成，作为三维表面的颜色贴图；不是扫描素材。白玫瑰提取其明暗细节，重新赋予象牙白色素。
- 512 × 512 程序化微表面贴图提供表面起伏，使用 mipmap 控制远处闪烁。移动端保留凹凸与颜色纹理，使用较轻的 Phong 光照和薄片散射近似；桌面使用物理材质及粗糙度贴图。
- 花瓣外缘增加卷曲，根部增加遮蔽花蕾，减少侧面露底；以曲面导数计算法线，让稀疏网格仍保留连续的明暗层次。
- 满天星包含连续的分叉细茎、五瓣小花与淡黄色花心，穿插在花冠内部和外缘。
- 叶片具有锯齿轮廓和分叉叶脉；缎带包含环形束带、双侧蝴蝶结和弯曲垂带。

纹理及完整生成提示见 [src/assets/README.md](src/assets/README.md)。所有运行资源均打包在本项目内，无外部模型或字体下载。

## 实现与性能

- `src/bouquet.js`：花束布局、花茎、满天星、缎带及实例化。
- `src/rose.js`：单朵玫瑰的花瓣曲面和植物结构，花束使用较低的曲面采样密度。
- `src/materials.js`：红白花瓣色素、微表面贴图、反光与薄片散射。
- `src/main.js`：场景、资源加载、灯光、相机、触摸控制与按需渲染。
- `src/quality.js`：设备像素比预算、绘制窗口裁剪和持续低帧率时的分辨率调整。
- `src/style.css` / `tokens.css`：响应式页面与视觉变量。
- `tests/`：花束配色、花茎收拢、内部满天星、几何有效性和渲染预算检查。

红白玫瑰共享花瓣几何体，按材质实例化；叶片和满天星小花也复用几何体。正常绘制为 13 次调用。桌面约 50 万个三角面；以粗指针识别的移动设备约 21.5 万个三角面，花瓣根部使用较少网格，外缘保留细分。所有玫瑰和满天星均保留。

像素比上限为 1.75。纵屏移动端只绘制花束所在的画布区域，使用原全页投影坐标，因此花束的位置和比例保持一致；在 430 × 932 的模拟视口下，缓冲区为 752 × 1011，相比上一版整屏 1.5 像素比的 645 × 1398，像素总量减少约 16%，同时提高了绘制清晰度。

手机触摸事件仅累积输入，每帧统一更新相机，手势期间连续绘制，并固定分辨率。自动动画的 90 帧平均耗时超过 25ms 时，可降低 0.25 像素比，最低降到 1.5；长时间静止不计入采样。旋转时复用静态柔和阴影，停止操作后按需渲染，页面隐藏时暂停绘制。

构建使用相对资源路径，可部署在 `/rose/` 等子目录。将 `dist/` 的完整内容上传到对应目录，完整替换 `index.html` 与 `assets/`。若线上页面末尾已有 `dy>` 等残留字符，需要完整覆盖整个 `index.html`，确认最后一个 `</html>` 之后没有残留文本或重复标签。入口 HTML 应设置 `Cache-Control: no-cache`，带哈希的 `assets/` 文件可以长期缓存；更新后若手机仍显示旧页面，可先加上新的查询参数验证。

自动检查覆盖手机触摸旋转、批量触摸输入、双指缩放、手势取消、空闲渲染，以及几何、着色器和绘制窗口预算。浏览器手机模拟不能代替 iPhone 真机帧率测试，实际体验仍需在设备上确认。
